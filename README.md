# 💧 LimpiaYA - Backend Server

Este es el servidor backend para la aplicación móvil LimpiaYA, construido para gestionar la autenticación de usuarios y la base de datos en la nube.

## 🚀 Tecnologías Principales
*   **Framework:** Java / Spring Boot
*   **Base de Datos:** PostgreSQL (Alojado en Neon.tech)
*   **Seguridad:** Google OAuth 2.0 (Tokens JWT)
*   **Despliegue:** Render

## ⚙️ Configuración de Variables de Entorno
Para correr este proyecto, el servidor necesita las siguientes variables de entorno:
*   `DB_URL` (Ej: jdbc:postgresql://...)
*   `DB_USER`
*   `DB_PASSWORD`
*   `PORT`
